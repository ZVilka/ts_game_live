# Игра «Жизнь»

Браузерная реализация клеточного автомата «Жизнь» Конвея на TypeScript.

Проект демонстрирует работу с HTML Canvas, DOM API, ES Modules и объектно-ориентированным подходом в TypeScript.

## Возможности

- генерация начального состояния игрового поля;
- отрисовка клеток через Canvas API;
- ручное добавление живых клеток мышью;
- запуск, пауза и перезапуск симуляции;
- изменение скорости жизненного цикла;
- подсчёт количества прошедших циклов;
- автоматическое завершение симуляции при стабилизации состояния.

## Технологии

- TypeScript
- JavaScript ES Modules
- HTML5
- CSS
- Canvas API
- DOM API

## Структура проекта

Основная логика разделена на отдельные модули:

- `App` — управление состоянием приложения и пользовательскими действиями;
- `Field` — игровое поле, расчёт следующего поколения и отрисовка;
- `Cell` — модель отдельной клетки;
- `helpers` — вспомогательные функции.

## Локальный запуск

Клонировать репозиторий:

```bash id="4m16qo"
git clone https://github.com/ZVilka/ts_game_live.git
cd ts_game_live
```

Скомпилированные JavaScript-файлы уже находятся в репозитории, поэтому дополнительная сборка для запуска не требуется.

Запустить локальный HTTP-сервер:

```bash id="8o24s4"
npx http-server src -p 5500
```

Открыть в браузере:

```text id="hzij80"
http://localhost:5500
```
